## Versioning decision

- Part C removes a documented consumer artifact (`docs/theme-preview.html`) and a public npm script (`build:preview`). This is a **Removed** change that consumers referencing the preview URL or the script will notice.
- Per semver: removing a documented artifact + script is a breaking change for tooling that referenced them. However, the library's runtime public API (components, theme exports) is unchanged.
- **Decision:** bump minor → `0.18.0`. Rationale: a removed npm script + removed docs file is a non-patch change to the developer surface; minor bump signals "review the changelog before upgrading tooling." (No `major` bump because the runtime component API is unchanged and the project is pre-1.0.)
