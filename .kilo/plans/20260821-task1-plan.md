## 0. Scope & decisions (pre-encoded — do NOT change)

- **Visual-only toggle.** The header band (`.cba-module-container__header`) stays in the DOM when hidden. Hiding is CSS-driven via `display: none`. Do NOT use `@if` / structural removal (that pattern is reserved for the optional footer slot).
- **Host-modifier pattern.** A new host class `cba-module-container--header-hidden` is bound on the `:host` element. The SCSS rule uses the `:host(.modifier) .child` selector per the AGENTS.md host-modifiers note. Do NOT use a plain descendant selector `.cba-module-container--header-hidden .cba-module-container__header` (broken under Angular emulated encapsulation).
- **Signal input API.** Use Angular `input<boolean>(true)`. Do NOT use `@Input()`.
- **Strictly additive change.** No existing host binding, template node, or CSS rule is modified. Only additions.
- **Default `true`.** Existing consumers that do not bind `showHeader` keep current behaviour.
- No template change required — the header `<div class="cba-module-container__header">` already exists in `module-container.component.html` (line 1).
