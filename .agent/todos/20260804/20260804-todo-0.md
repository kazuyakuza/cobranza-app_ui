# Phase 8 — Palette Refresh (Minimal Yet Warm)

**Library:** `@cobranza-apps/ui`  
**Chosen direction:** **Minimal Yet Warm**  
**Source hexes (core palette):**

| Hex | Role hint (starting point, not rigid) |
| ----- | ---------------------------------------- |
| `#EAE7DC` | Light warm canvas / page background |
| `#D8C3A5` | Warm sand — secondary surface / inset / soft chrome |
| `#8E8D8A` | Warm gray — borders, muted UI, secondary text candidate |
| `#E98074` | Soft coral — secondary accent / warning-leaning accent |
| `#E85A4F` | Stronger coral-red — primary accent / danger / CTA emphasis |

**Preview reference:** `docs\theme-preview.html` (theme “Minimal Yet Warm”)

## Objective

Replace the current flat mid-gray / failed lightened dark palette with a **warm, calm, professional** system based on Minimal Yet Warm so that:

- The Shell + modules feel approachable (not near-black, not muddy gray fog)
- Surfaces have clear hierarchy (canvas ≠ panel ≠ elevated ≠ inset)
- Text is highly readable
- Accents are intentional and not overused on large areas

This phase is **tokens + theme application only**. No new components.

## Important constraints

- Keep **token names** stable (`--cba-bg-primary`, `--cba-text-primary`, etc.) so components do not need API changes.
- Desktop-only.
- Spanish UI copy rules unchanged.
- **Do not** treat the table above as a 1:1 mandatory mapping if a different assignment reads better.
- The implementing agent **may and should**:
  - Reassign which source hex (or derived mix) is used for canvas / panel / elevated / inset / text / borders / accents
  - Derive **tints and shades** of the same five colors (mixes toward lighter/darker warm neutrals) when the raw set is not enough for 4 surface levels + readable text
  - Soften or strengthen `#E98074` / `#E85A4F` usage if coral appears in the wrong place (e.g. avoid large coral backgrounds; prefer them for accents, status, CTAs, focus-related emphasis)
  - Add neutral warm steps (e.g. off-white cream, deeper taupe) **only as variations of this palette**, not by importing a new unrelated scheme
- Goal is “looks right in the running Shell”, not mathematical purity of the five hexes.

## Design principles

1. **Warm, not gray-for-gray’s-sake** — neutrals stay in the beige/sand/taupe family.
2. **Hierarchy first** — at least four surface levels visibly distinct.
3. **Text contrast first** — primary/secondary/muted must read clearly on panel and elevated surfaces.
4. **Coral is accent, not wallpaper** — `#E85A4F` / `#E98074` should not dominate large backgrounds unless a deliberate, small use works better.
5. **Calm professional** — modern and friendly; not aggressive dark mode; not sterile pure white SaaS unless a soft cream panel truly fits this palette.

## Suggested starting mapping (agent may adjust)

Use as a **first draft only**:

| Token group | Suggested direction |
| ------------- | --------------------- |
| Canvas (`--cba-bg-primary`) | Light warm `#EAE7DC` or a slightly softer/darker derived cream-sand |
| Panel (`--cba-bg-secondary`) | Cleaner light surface above canvas (derived off-white warm or stepped `#EAE7DC`) so modules read as cards |
| Inset (`--cba-bg-tertiary`) | `#D8C3A5` or a mix of sand + gray for table headers / input wells |
| Elevated (`--cba-bg-elevated`) | Lightest usable warm surface for module header / dropdowns / popovers |
| Text primary | Dark warm near-black/taupe (derived), not harsh pure black if avoidable |
| Text secondary / muted | Based on `#8E8D8A` with enough contrast on panel |
| Borders | From `#8E8D8A` / sand mixes — visible on light surfaces, not muddy |
| Accent primary | Prefer coral `#E85A4F` or a controlled variant; alternative: deep taupe if coral CTAs feel too loud for primary buttons |
| Success | Derive a calm green compatible with warm neutrals (not in source set — agent should add a harmonious success green) |
| Warning | `#E98074` or softer coral |
| Danger | `#E85A4F` or slightly deeper coral-red |
| Shadows | Soft warm-tinted shadows so modules lift off canvas without harsh black bloom |

If the first draft fails contrast or hierarchy, **change the mapping** before shipping.
