# Fix secondary button background color [DONE]

## Problem

The `cba-button` component's `secondary` variant uses `background-color: var(--cba-bg-secondary)` (`#F2F0E8`).

When placed inside a module whose body also uses `--cba-bg-secondary`, the button becomes invisible — it blends into the background with no visible border or contrast.

## Example

In the **"New Customer"** form (`demo-customer-form`), the **Cancel** button (`variant="secondary"`) is invisible because:
- Module body background = `--cba-bg-secondary` = `#F2F0E8`
- Secondary button background = `--cba-bg-secondary` = `#F2F0E8`

## Expected behavior

The secondary button should use `background-color: var(--cba-bg-elevated)` (`#FDFCF8`) so it is visibly distinct from `--cba-bg-secondary` surfaces.

This matches the token documentation in the demo's **Buttons** section, which states:
> `.cba-button--secondary · var(--cba-bg-elevated) · var(--cba-border-subtle)`
