## Project Info

All agents must read the following project-info files at the beginning of each task to understand the project's context, architecture, and technical specifications:

- [Project Brief](.agent/project-info/brief.md) — source of truth for scope, design tokens, component specs, and integration notes.
- [Product Info](.agent/project-info/product.md) — problem definition, product goals, target consumers, UX focus.
- [Context](.agent/project-info/context.md) — current work status, recent changes, immediate next steps, open risks.
- [Architecture](.agent/project-info/architecture.md) — high-level architecture, folder layout, build strategy, public API, integration patterns.
- [Tech Stack](.agent/project-info/tech.md) — exact versions, dependencies, scripts, development setup, tooling constraints.

Also read the [Project Info Instructions](.agent/project-info/instructions.md) for guidance on how to use these files.
